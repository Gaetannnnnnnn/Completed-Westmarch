⚔ Prérequis — Soruta Completed Westmarch

Foundry VTT v13+ (ciblé v14) · D&D 5e v3 · Mis à jour 03/08/2026

Un seul module — soruta-completed-westmarch — regroupe désormais toutes les fonctionnalités (party, chat, combat, temps morts, toolkit, fiches Relations / Bestiaire / Carnet, carte, midi range fix, tutoriel). Il n'y a plus aucune dépendance entre modules Soruta : chaque fonctionnalité s'active individuellement dans les paramètres. Ne restent que les modules externes ci-dessous ; chaque feature qui en dépend se désactive silencieusement si le module tiers est absent.
